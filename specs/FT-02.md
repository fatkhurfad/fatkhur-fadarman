# FT-02 Input Berat dan Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dalam kilogram dan langsung mengetahui apabila aturan minimum charge 3 kg diberlakukan.

## Alur
1. Pengguna melihat kolom estimasi berat terisi awal `3` kg.
2. Pengguna mengetik angka berat (memakai koma atau titik) atau menekan tombol `-` dan `+`.
3. Jika berat valid lebih dari 0 dan kurang dari 3 kg, pemberitahuan minimum charge 3 kg muncul secara otomatis.
4. Jika berat kosong, 0, negatif, atau melebihi 100 kg, pesan error muncul saat dikirim atau saat nilai tidak valid.

## Data
- `STORE_INFO.minimumChargeKg` (`3`) di `src/config.ts`.
- `WEIGHT_LIMITS` (`minKg: 0.1`, `maxKg: 100`, `stepKg: 0.1`, `buttonStepKg: 0.5`, `defaultKg: 3`) di `src/config.ts`.

## Aturan dan rumus
- Rumus BL-01: `W_ditagih = max(3.0, W_aktual)` untuk `W_aktual >= 0.1`.
- Satuan: kilogram (kg).
- Batas nilai valid: `0,1` kg hingga `100` kg.
- Kolom menerima tanda koma (`,`) maupun titik (`.`) sebagai pemisah desimal.
- Nilai 0, minus, kosong, atau bukan angka tidak valid dan memblokir pengiriman pesanan.

## Input dan validasi
- Kolom `weight` (wajib): harus berupa angka pada rentang `0,1` sampai `100`.
- Pesan error kosong/0/tidak valid: "Masukkan berat cucian minimal 0,1 kg, contoh: 2,5."
- Pesan error melebihi batas atas: "Masukkan berat maksimal 100 kg, contoh: 12,5."

## Tampilan dan teks
- Label selalu terlihat: "Estimasi Berat Cucian (kg)" dengan teks bantuan singkat.
- Tombol penyesuaian `-` dan `+` berukuran minimal 44 x 44 px di sisi input.
- Pemberitahuan minimum charge (tampil saat `0 < W_aktual < 3`): latar `bg-amber-50`, teks `text-amber-800`, ikon `Info`, teks: "Ketentuan minimum charge 3 kg berlaku. Berat ditagih dihitung 3 kg."

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-01 / TC-01 | Berat `2` kg pada Cuci Lipat | Berat ditagih `3` kg, notifikasi min. charge muncul, biaya utama `Rp18.000` | PRD |
| TC-03 | Berat `0` atau kosong | Form menolak kirim dan menampilkan pesan error pada kolom berat | PRD |
| FT02-3 | Input memakai koma `1,8` kg | Terbaca sebagai `1,8` kg, berat ditagih `3` kg, notifikasi min. charge muncul | PRD (Kasus A) |
| FT02-4 | Input berat `-2` atau `150` kg | Dianggap tidak valid dan menampilkan pesan error bercontoh | Tambahan |
